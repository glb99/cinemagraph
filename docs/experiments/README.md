# Experiments log

One short file per experiment, named `YYYY-MM-DD-short-slug.md`. Copy `TEMPLATE.md`.

The point is to save future-you from re-running dead ends: this is a lab, not a backlog
(see `docs/DESIGN.md` §6), and most experiments here will end in "didn't work" or
"worked but not worth the dependency weight" — that's a successful entry, not a failure
to hide. Write the note *especially* when something doesn't pan out.

Keep entries short — a few paragraphs, not a report. If code came out of it, link the
commit/branch; don't paste diffs here.
